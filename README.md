# HomeCrew

App iOS para organizar a família: agenda do dia, membros da família (incluindo pais separados, avós e ama), tarefas, atividades com quem leva e quem traz, e episódios de doença.

- Design: Direção A · Clara (iOS nativo)
- Stack: SwiftUI, iCloud (CloudKit), iOS 17+
- Tickets do MVP: issues #1 a #20
